## Practice 1 - Variables and Output

```python
name = "Indhu"
course = "VLSI"
year = 2026

print("Name:", name)
print("Course:", course)
print("Year:", year)
```

### Expected Output

```text
Name: Indhu
Course: VLSI
Year: 2026
```

## Practice 2 - Basic Calculation

```python
a = 20
b = 10

print("Addition:", a + b)
print("Subtraction:", a - b)
print("Multiplication:", a * b)
print("Division:", a / b)
```

### Expected Output

```text
Addition: 30
Subtraction: 10
Multiplication: 200
Division: 2.0
```

## Practice 3 - User Input

```python
name = input("Enter your name: ")
print("Welcome,", name)
```

### Expected Output

```text
Enter your name: Indhu
Welcome, Indhu
```

## Practice 4 - Simple Function

```python
def calculate_power(voltage, current):
    return voltage * current

power = calculate_power(5, 2)
print("Power:", power, "W")
```

### Expected Output

```text
Power: 10 W
```
