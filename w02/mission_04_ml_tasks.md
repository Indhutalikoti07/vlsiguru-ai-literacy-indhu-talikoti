# Mission 4 — ML task types

| Problem | Task | Input | Expected output |
|---|---|---|---|
| Email spam detection | Classification | Message text/features | Spam or not spam |
| House price estimation | Regression | Area, location, age | Price in currency |
| Group customer habits | Clustering | Purchase patterns | Cluster assignment |
| Flag abnormal motor vibration | Anomaly detection | Sensor time series | Anomaly score or flag |
| Compress many sensor variables | Dimensionality reduction | High-dimensional measurements | Lower-dimensional representation |
| Rank recommended courses | Recommendation/ranking | Preferences and course attributes | Ordered course list |
| Predict chip timing result | Classification (semiconductor) | Constraints and design measurements | Pass or fail |
| Estimate chip power | Regression (semiconductor) | Activity, voltage, design features | Estimated watts |
| Detect unusual wafer-test patterns | Anomaly detection (semiconductor) | Test measurements | Suspicious sample flag |

**Paradigm ≠ task:** Supervised learning can be used for both classification and regression. Clustering often uses unsupervised learning. Different algorithms can solve the same task, and an anomaly detector may be trained with or without labelled examples. [S1]
