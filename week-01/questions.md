### A - Answer

## Q3 - What Happens When We Ask an LLM a Question?

### A - Answer

A prompt is the instruction given to a language model.
The model processes the text as tokens and uses context to
estimate possible next tokens.

A token can be a word, part of a word, or punctuation.
The model generates a response by selecting tokens successively.

Training teaches a model patterns using data. Inference is
the process of using a trained model to produce an answer.

### E - Evidence

Reference:
https://help.openai.com/en/articles/8313428-does-chatgpt-tell-the-truth

### V - Verification

I will check that the reference supports the explanation of
language-model behavior and its limitations.

### R - Reflection

A fluent answer is not necessarily a correct answer.
Important claims should be verified independently.

### Flow

Prompt -> Tokens -> Model Processing -> Probability
Distribution -> Next Token Selection -> Generated Response

## Q6 - What Is an AI Agent?

### A - Answer

An LLM processes and generates language.

An LLM application uses a language model in software.
A RAG system retrieves relevant external information to
help the model produce a grounded response.

A tool-using assistant can call tools such as search or
a calculator. An AI agent can use models, tools, and
feedback to work toward a goal.

Example:
A task-planning agent could organize a to-do list by
reviewing tasks, sorting them by priority, and suggesting
a daily schedule.

### E - Evidence

References:
- https://www.ibm.com/think/topics/ai-agents
- https://cloud.google.com/use-cases/retrieval-augmented-generation

### V - Verification

I will compare these descriptions with the references and
check the differences between retrieval, tool usage, and
multi-step agent workflows.

### R - Reflection

I learned that an AI agent is more than a text response.
It may use tools and feedback to complete multiple steps.
Human oversight is still important for consequential actions.

### Flow

User Request -> AI Model -> Tool Call -> Tool Result
-> Decision -> Final Response

## Q10 - Personal AI Verification Protocol

### A - Answer

My seven-step verification protocol is:

1. Define the problem clearly.
2. Inspect the assumptions and input information.
3. Check the evidence and source quality.
4. Test the result using an example or calculation.
5. Compare the result with an independent source or method.
6. Evaluate the risks and identify the required human approval.
7. Accept, reject, or revise the answer and document the decision.

### E - Evidence

Example: An AI assistant calculates the cost of 6 items
priced at Rs. 35 each.

Independent calculation:
6 x 35 = Rs. 210.

### V - Verification

I can check the answer using a calculator. If the AI gives
a different amount, I will inspect the calculation and
correct the result before accepting it.

### R - Reflection

I learned that an answer should be inspected, tested,
and documented before it is used. I will improve this
protocol as I learn more about AI and engineering.
